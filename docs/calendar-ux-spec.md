# Calendar UX Spec (MVP)

## Admin / Trainer Calendar

- Day/week/month modes.
- Fast add/edit of sessions.
- Capacity visibility and overbook prevention.
- Quick access to check-in list and trainer notes.

## Client Calendar

- Month-first availability view.
- Session card with capacity and room.
- One-tap booking/cancel action.
- Waitlist state when no capacity remains.

## UX Principles

- Strong loading/empty/error states.
- Conflict and rule violations shown with clear reasons.
- Timezone-safe rendering and API contract.
