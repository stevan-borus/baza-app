# Cross-tab drills carry `returnTo` and `filter*` query params

When the user taps a row in one tab's sub-page that conceptually belongs to another tab (e.g. tapping a Reformer 12-pack revenue row in Izveštaji/Prihod → land in Naplata filtered by that PackageType), the drill is a `router.push` to the *other* tab's route, not a stack push inside the current tab. This is forced by ADR-0001 (per-tab Stacks): a route can only be pushed inside the stack that owns it. To compensate for the lost back-stack we attach two query params: `filter*` keys that the destination screen interprets, and `returnTo=/some/path` that the destination renders as a return pill ("← Nazad u Izveštaji"). The destination clears its own state when the pill is tapped, since the back gesture wouldn't return to the originating tab on its own.
