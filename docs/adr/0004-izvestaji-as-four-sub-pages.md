# Izveštaji is a hub, not a single scrolling page

The Izveštaji tab was a single screen stacking Prihod, Iskorišćenost, Rezervacije, Paketi sections with one shared period pill. The screen grew unreadable: each section got a couple of GlassCards of attention before fatigue, the shared pill prevented comparing one metric in "Mesec" against another in "Godina", and most sections rendered only a single row instead of the full breakdown they imply (Po sali showing 1 of 2 Salas, Po treneru showing 1 of N trainers). We split it into four sub-stack pages, each owning its own period pill and rendering full breakdowns. The landing page is a 4-card grid of headline numbers with delta arrows; tapping a card pushes into the sub-page. This matches Model A (ADR-0001) by living inside the Izveštaji tab's own Stack — the tab bar stays visible, back-stack is per tab, no leaking.
