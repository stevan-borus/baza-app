# Admin tab bar collapses to four; catalog CRUD moves into the avatar menu

The admin tab bar had six visible items (Pregled, Klijenti, Paketi, Naplata, Izveštaji, sessions-leak) where three were daily-operations screens and three were rarely-touched catalog editors (Tipovi treninga, Sale, PackageTypes via Paketi). The mix made the bar crowded and conceptually fuzzy — "schedule" and "settings" looked equally important. We split intent: the tab bar carries the four daily-operations screens (Pregled / Klijenti / Naplata / Izveštaji), and the catalog CRUDs live behind the admin avatar menu in the top-left. Aktivne dodele — the analytics view that used to be inside Paketi — moves up into Izveštaji/Paketi (its natural home, per ADR-0004). The sessions tab disappears entirely under Model A (ADR-0001), since session detail now lives inside Pregled's and Klijenti's stacks.
